# 第一阶段验收记录与下一步

自动报告：`ae-integration-result.json`，运行平台是真实 AE 24.0.3x2，不是模拟 AE。

1. 激活验收合成，选择产品，读取工程。检查位置关键帧时间和值、透明度表达式及错误字段。
2. 使用 @ 搜索产品名称或 ID；重名时按 ID 区分。清除其他目标。
3. 用固定测试方案验证 CEP 执行桥，再使用真实 API 中文生成方案。执行前检查目标与覆盖范围。
4. 输入“回弹减半、提前 0.2 秒结束”，检查新结束时间和超调幅度，确认仍是三枚原生关键帧。
5. 撤销，比较关键帧时间、数值、缓动、空间切线与表达式；背景和标题保持不变。
6. 方案生成后手动改图层名称或位置，旧方案必须报 STALE_STATE。
7. 输入会出错的表达式；执行器报告 rolled_back。查看原表达式恢复。partial 表示回滚不完整，需要人工检查，不能显示成功。
8. 请求期间取消：只取消模型请求，不会撤销此前 AE 修改。AE 执行开始后不提供伪取消。
9. 重新打开已保存工程：聊天可恢复，但必须重新读取状态；历史不会作为实际工程状态。动画配方暂不跨执行器重载恢复。
10. 参考迁移：加载 GIF/视频片段、映射一个参考对象到产品图层，检查方案只含 motionPath；应用后检查位置关键帧末点保持原终点，背景和标题未变，重复回执不重复加帧，撤销完整恢复。

ChatGPT 本机授权和 Responses 代码已新增，尚未真实账号在线验收。参考轨迹写入执行器另有 AE DOM 模拟测试，但这不代替真实 AE。未完成项：CEP 11 中启动 Keychain helper、浏览器登录与额度授权、图片帧请求和参考视频动画效果。捕获预览、模型回看、Claude 等未实现能力不宣称可用。

失败策略：操作前全量验证。每次 mutation 一个 AE undo group；捕获失败时用原始快照恢复已触及属性。回滚失败明确返回 partial 和 recoveryErrors。相同任务 ID 只在当前执行器会话内去重；关闭/重启后先读状态，不重放旧任务。
