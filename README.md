# Motion Relay · 0.2.0 开发版

这是实际 CEP 扩展与 ExtendScript 执行器，不是网页界面原型。当前包含基础动画和参考视频迁移开发版，尚不能作为部门正式发布版本。

## 参考视频迁移（开发版）

1. 打开面板，选择本地参考视频或 GIF 并填写起止秒数（GIF 以一轮播放为范围）。运动较快时可提高采样密度。若 AE 无法解码源视频，可尝试 VP8 / VP9 WebM。
2. 选择一个已有的无父级二维图层，说明参考画面中与它对应的对象。可补充目标时长、回弹和终点要求。
3. 展开「ChatGPT 账号与模型」，通过系统浏览器登录并确认允许 Motion Relay 使用 ChatGPT 套餐额度，再选择该账号提供的模型。点「分析参考动效」后，片段抽帧会发送给所选模型。
4. 查看抽帧、运动描述和影响范围。确认应用后，原图层上会生成可编辑的位置关键帧。已有位置关键帧会在确认后整体替换，动画终点保留。可以播放 AE 时间轴检查并撤销。
5. 继续调整时可保留同一个参考与目标，修改文字描述并重新分析。已有迁移轨迹作为当前工程状态传入。

当前实现按模型估计的点写入线性插值位置关键帧。精确跟踪、父级及三维适配、逐字错峰、遮罩、描边生长和实际画面捕获仍待实现。此前的真实 AE 报告仅覆盖基础动画和表达式。当前版本的线上模型与参考迁移还没有在真实 AE 中完成全链路验收。下方第一阶段操作为历史记录。

## 打开与使用

1. 保存当前工程并重启 AE。打开 **窗口 → 扩展 → Motion Relay（开发版）**，可拖动停靠。
2. 激活合成，在 AE 选中产品图层，再按「读取工程」；或在面板 `@` 搜索框按名称/稳定 ID 搜索并勾选目标。这里是目标搜索，不是聊天正文内的 @ 自动补全。
3. 展开「ChatGPT 账号与模型」，点「连接 ChatGPT」。浏览器会显示授权对象和请求权限；同意后，模型从该账号的可用列表载入。OAuth 令牌保存在本机 macOS 钥匙串，不需要输入 API 密钥。
4. 输入中文要求，例如「从左侧 300 像素入场，1 秒结束，轻微回弹，保留最终位置」。生成后核对合成、图层、属性和 JSON 方案，再执行。
5. 再输入「回弹减半，提前 0.2 秒结束」。同一执行器会话内，模型会收到当前动画配方。已有动画覆盖需要勾选确认。
6. 「撤销上次修改」恢复该次全部受影响属性；若目标被外部编辑，会拒绝覆盖，改用 AE 原生撤销历史。
7. 无 API 时可使用「无需模型的真实 AE 连通测试」，固定参数明确标注，不冒充 AI 结果。

模型调用会发送当前合成的图层属性、表达式、名称、最近对话和参考片段抽帧。参考视频文件本身不会上传。ChatGPT 账号须在授权时允许应用使用套餐额度；模型与图像能力以账号实时提供的列表及实际请求结果为准。每位同事使用自己的 ChatGPT 账号和额度。

前端不提供任意脚本执行入口；表达式是明确的代码审阅模式。模型返回的任意脚本字段会被拒绝。已有位置表达式启用时不执行位置动画。每次最多 20 个操作、300 图层扫描、单属性 500 关键帧；超限不截断后继续写入。

动画执行会替换目标位置属性的所有关键帧。新动画终点来自执行前结束时间的属性值；连续修改保留配方终点。只修改列出的属性，不创建重复图层。

本机已通过 11 项真实 AE 检查，见报告。首次测试发现并修复了 ExtendScript 嵌套三元运算兼容问题，以及二维图层位置属性实际要求三维空间切线的问题。调试过程中创建了多份带时间戳的独立验收合成，保留在当前未保存工程内供检查。

还需人工/在线验收：AE CEP 11 内加载 Keychain helper、首次 ChatGPT 登录与额度授权、真实 Responses 请求和图片输入、中文多轮意图及参考动画结果。登录需要用户在浏览器完成授权；自动测试不会读取或模拟任何账号令牌。

## 架构

- `panel/`：中文界面、目标选择、方案审阅和任务状态；通过 CEP `evalScript` 调用固定 dispatcher。
- `core/contract.js`：前端 / 执行端共享 ES5 操作契约与权限范围校验。
- `host/`：ES3 兼容 JSON 编解码、真实 AE 查询、原生关键帧、事务快照、失败回滚、一次撤销。
- `core/model.js`：受约束的 Responses 请求与超时取消。
- `runtime/chatgpt.js`：系统浏览器 OAuth、127.0.0.1 一次性回调、ID Token 验签、刷新与 Responses SSE。没有后台常驻服务。
- `runtime/keychain.m`：Apple Security.framework 辅助程序，把 OAuth 凭据加密存进 macOS 钥匙串。
- `core/session.js`：本地会话。`modules/ports.js` 为后续媒体、捕获、生成、规则及多供应商的接口边界。

本项目的 OAuth 流程独立按公开协议实现，没有复用 OpenAI 的非商业许可 DevKit。Keychain 辅助程序依赖 macOS Foundation / Security 框架。仓库采用 MIT 许可证；公开发布前仍需将 `LICENSE` 中的版权归属改为实际权利人，并进行代码、构建物和部门批准范围审阅。当前 GitHub 连接没有创建新仓库的能力，因此源码暂留在本机，尚未公开发布。

官方依据与实现决策见 `docs/sources.md`；验收步骤见 `docs/acceptance.md`。
